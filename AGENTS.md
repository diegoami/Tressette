# Project instructions

This repository keeps its guidance in [`CLAUDE.md`](CLAUDE.md). **Read it before
changing anything.** It covers the UI check that must pass after any UI change,
the unit tests that must pass after any engine change, the card-size budget, the
rule that the engine is frozen once it ships, and the conventions for player
text and the card art.

OpenCode loads `AGENTS.md`, while Claude Code loads `CLAUDE.md`. This file
exists so both tools share one source of truth instead of a copy that drifts —
do not duplicate the content here.
